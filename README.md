# Практикум по фармакологии

Для просмотра откройте `farma-web/index.html` в браузере. Интернет для работы тестов не нужен.

Для публикации распакуйте `farma-web.zip` в корень сайта на статическом хостинге. Файлы `index.html`, `style.css`, `app.js` и `bank.js` должны находиться в одной папке. Сборка и сервер приложений не требуются.

В этом выпуске 1102 записи банка вопросов из 31 исходного теста. В каталоге 11 модулей по курсам и 29 занятий. Для четырёх курсов используются готовые модули из Exam55. Для остальных семи модуль объединяет вопросы занятий соответствующего курса. Два занятия по общей фармакологии составлены из вопросов первого модуля.

Оценка рассчитывается по исходному ключу. Если в ключе несколько правильных вариантов, вопрос засчитывается только при выборе всех правильных вариантов без лишних. Попытки сохраняются в браузере. Ключи содержатся в файле `bank.js` и доступны посетителям сайта, поэтому сайт подходит для самопроверки.

## Пополнение банка

Для оставшихся тестов из `Exam55.zip` нужен текстовый экспорт с вопросами и ответами. В редакторе откройте `TestEd.exe → Файлы → Экспорт… → Экспорт тестов в текстовый файл`. Выберите курс и диапазон тестов. Если редактор сохраняет курс в `Examenat.txt`, скопируйте его в отдельный файл до следующего экспорта.

Чтобы обновить банк из текстовой выгрузки Exam55, выполните из папки проекта:

```powershell
node tools/import-exam55.mjs 'путь/к/Exam.txt'
```

Если выгрузка содержит только новые тесты, передайте её вместе с уже импортированными файлами из папки `exports`. Один и тот же тест должен присутствовать только в одной из выгрузок.

```powershell
$inputs = Get-ChildItem -LiteralPath exports -Filter '*.txt' -File | Sort-Object Name | ForEach-Object FullName
node tools/import-exam55.mjs @inputs 'путь/к/новому-курсу.txt'
```

После импорта обновите `bank.js` на хостинге. При изменении банка сайт начинает хранить попытки в отдельной версии, чтобы старые ответы не сопоставлялись с изменившимися заданиями.

Файлы `.EXA` из `Exam.rar` открываются в отдельном редакторе `ExamEdit.exe`. Для переноса из них нужна читаемая выгрузка или копия вопросов с вариантами и правильными ответами с разбивкой по исходным тестам.
